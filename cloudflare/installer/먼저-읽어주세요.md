# 포켓몬 수집 위젯 설치

설치는 노션 템플릿 복제 → 개인 Worker에 코드 붙여넣기 → 연결 페이지에서 주소 생성 → 노션 임베드 순서입니다. 사용자는 Node.js나 GitHub를 설치·연결할 필요가 없습니다.

## 1. 노션 준비

1. 본인만 사용하는 포켓몬 전용 워크스페이스를 만들고 수집 DB 템플릿을 복제하세요. 기존 워크스페이스의 비공개 DB도 사용할 수 있습니다.
2. 같은 워크스페이스에서 노션 내부 연결을 생성하고 콘텐츠 읽기·삽입·업데이트를 허용하세요: https://www.notion.so/profile/integrations
3. 복제한 원본 DB의 `··· → 연결 추가`에서 해당 연결을 추가하세요.
4. 원본 DB의 링크를 복사하세요. 상위 일반 페이지나 연결된 보기의 링크 대신 원본 DB를 사용합니다.

수집 DB의 필수 속성은 네 가지입니다. 기존 추가 속성과 포획 기록은 보존합니다.

| 속성 이름 | 유형 |
|---|---|
| 이름 | 제목 |
| 폼 식별자 | 텍스트 |
| 배경 식별자 | 텍스트 |
| 즐겨찾기 | 체크박스 |

## 2. 개인 Worker 준비

1. https://dash.cloudflare.com/ 에 가입·로그인합니다.
2. Workers & Pages에서 새 Worker를 만들고 배포합니다. 이름은 `pokemon-collection-widget`을 권장합니다. 저장소를 연결하지 않았던 테스트 Worker는 계속 사용해도 됩니다. 이전 Durable Object를 실제로 배포했던 Worker는 보존하고 새 Worker에 설치하세요.
3. 동봉한 `worker.js`를 텍스트 편집기로 열고 전체 내용을 복사합니다.
4. Worker의 `Edit code`에서 기본 코드를 동봉 코드로 전체 교체하고 `Deploy`합니다.
5. `Settings → Variables and Secrets`에서 종류 **Secret**, 이름 **NOTION_TOKEN**, 값은 노션 내부 연결 토큰으로 등록하고 배포합니다.
6. Worker의 `https://….workers.dev` 주소를 복사합니다.

Bindings는 비어 있어도 됩니다. DB 주소는 다음 단계의 연결 페이지에서 입력합니다. 노션 API 토큰은 개인 Worker에만 등록하세요.

`worker.js`에서 한글 대신 `\uXXXX` 형태가 보여도 정상입니다. 파일을 복사할 때 한글이 깨지지 않도록 한글을 안전한 코드 표기로 저장하며, 실행할 때는 원래 한국어 이름과 문구를 사용합니다. 코드의 일부를 직접 바꾸지 말고 전체를 붙여넣으세요.

연결 오류가 `ë…¸`, `ì…` 같은 글자로 표시된다면 이전 Worker 코드를 복사할 때 한글이 깨졌을 가능성이 큽니다. 최신 설치 파일을 다시 받아 Worker 코드를 전체 교체하고 `Deploy`한 뒤 연결을 다시 시도하세요. `NOTION_TOKEN`은 유지하며, 노션 DB의 속성 이름을 깨진 글자로 바꾸지 마세요.

하루 포획 한도는 기본 3마리입니다. 필요하면 Worker의 일반 변수 `DAILY_LIMIT`에 1~100 사이의 정수를 등록하고 배포하세요. 한국 시간 자정을 기준으로 현재 노션 DB에 남아 있는 오늘의 포켓몬 기록을 셉니다.

## 3. 위젯 주소 만들기

1. https://pokemon.loraticon.com/setup.html 에 접속합니다. 내려받은 setup.html을 더블클릭해서 연결하지 않습니다.
2. 개인 Worker 주소와 복제한 원본 노션 DB 주소를 입력합니다. 노션 토큰을 HTML에 입력하지 않습니다.
3. `연결 확인하고 위젯 주소 만들기`를 누릅니다.
4. 연결에 성공하면 위젯 주소를 자동 복사합니다. 자동 복사가 허용되지 않으면 화면의 `위젯 주소 복사` 버튼을 사용하세요. 주소 입력란을 선택해 직접 복사할 수도 있습니다.
5. 사용할 노션 페이지에서 `/임베드`를 선택하고 위젯 주소를 붙여넣습니다.

연결할 때 수집 DB 안에 **위젯 설정** 페이지가 자동으로 추가됩니다. 이 페이지의 폼 식별자는 `__widget_settings_v1__`이며, 포켓몬 도감·오늘의 포획 횟수에서 제외됩니다. 페이지 안의 설정 블록에는 슬립모드·선택한 포켓몬과 배경·배경 즐겨찾기가 저장됩니다. 여러 기기에서 같은 위젯 주소로 연결하면 설정을 공유합니다. 포켓몬 즐겨찾기는 각 포켓몬 행의 체크박스와 연동됩니다.

## 기록과 포획 기회

- 잡은 포켓몬은 노션에 자동 추가합니다. 색이 다른 개체는 새로 뽑지 않습니다.
- 포획 전에 현재 DB에서 같은 폼 식별자를 조회해 이미 잡았다면 저장하지 않습니다.
- 오늘의 기록을 삭제하면 사용 횟수가 줄고 포획 기회가 돌아옵니다. 삭제한 포켓몬은 다시 수집할 수 있습니다.
- 설정 페이지와 과거의 색이 다른 기록은 포획 횟수에 포함하지 않습니다.
- 포획 중에는 위젯 버튼을 잠급니다. 같은 Worker 실행 인스턴스에 도착한 요청도 순서대로 처리합니다. 여러 기기가 서로 다른 실행 인스턴스에 동시에 저장하면 중복이나 한도 초과가 생길 수 있으며 엄격한 전역 잠금을 제공하지 않습니다.
- 설정 페이지를 삭제하면 연결 페이지에서 다시 준비할 수 있지만 그 페이지에 저장했던 화면 설정은 초기화됩니다.

## 개인 사용 안내

별도의 위젯용·설정용 토큰은 없습니다. Worker 주소와 DB 식별자를 아는 사람은 API로 기록을 조회하거나 변경할 수 있습니다. 개인 기기와 비공개 노션 페이지에서 사용하고, Worker 주소·위젯 주소를 공유하거나 공개 문서·SNS에 게시하지 마세요. 전용 워크스페이스와 CORS 출처 제한은 API 사용자 인증을 대신하지 않습니다.

이 버전으로 전환하면 기존 노션 기록과 추가 속성은 유지합니다. 이전 Cloudflare 저장소의 포획 이력과 화면 설정은 읽지 않습니다. 노션 체크박스 즐겨찾기는 유지되며 배경 즐겨찾기와 슬립 설정은 새 설정 페이지에서 다시 선택하세요. 이미 배포된 Durable Object는 삭제하지 않고 기존 Worker와 함께 보존합니다. 새 Worker 주소로 연결하면 됩니다.

로컬 자동 테스트·단일 JS 빌드와 실제 개인 계정 배포·노션 연결 검증은 구분합니다. 이 안내 자체가 실제 연결 완료를 의미하지는 않습니다.

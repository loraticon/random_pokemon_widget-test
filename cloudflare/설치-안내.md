# 개인 Worker 설치

현재 설치 방법은 [브라우저 붙여넣기 안내](installer/먼저-읽어주세요.md) 한 가지입니다. 설치 ZIP에는 `worker.js`와 안내 두 파일만 포함합니다. Node.js·GitHub·Cloudflare 저장소 바인딩은 사용자 설치에 필요하지 않습니다.

노션 템플릿 복제와 내부 연결 권한 추가 → 개인 Worker 코드 붙여넣기와 NOTION_TOKEN Secret 등록 → 공용 HTTPS 연결 페이지에 Worker·원본 DB 주소 입력 → 링크 생성·복사 → 노션 임베드 순서로 진행합니다.

공용 화면은 https://pokemon.loraticon.com 이며 API는 사용자의 개인 Worker에서 처리합니다. Worker 코드에 공용 origin과 기본 하루 한도 3이 포함되어 있습니다. 제작자용 WIDGET_ORIGIN과 사용자 선택 DAILY_LIMIT 일반 변수로 값을 바꿀 수 있습니다.

수집 DB에는 이름·폼 식별자·배경 식별자·즐겨찾기 네 속성을 사용합니다. 연결할 때 같은 DB 안에 `위젯 설정` 페이지와 JSON 코드 블록을 추가합니다. 설정 페이지는 포켓몬·횟수 집계에서 제외합니다. 배경 즐겨찾기·슬립모드·선택 화면은 설정 블록, 포켓몬 즐겨찾기는 해당 포켓몬 체크박스에 저장합니다. 기존 추가 속성과 노션 기록은 보존하며 일반 페이지를 입력해 새 DB를 자동 생성하는 경로는 제공하지 않습니다.

포획 한도·수집 여부는 현재 DB 기록에 따릅니다. 오늘 기록 삭제 시 기회가 복구됩니다. 중복은 조회 후 저장으로 막으며 같은 실행 인스턴스에서는 요청을 직렬화합니다. 여러 인스턴스·기기의 정확한 동시 요청까지 보장하는 전역 잠금은 없습니다. 노션 POST 응답이 불분명하면 먼저 DB에서 저장 여부를 확인합니다.

이번 버전은 이전 Durable Object를 읽지 않습니다. 기존 노션 체크박스와 수집 기록을 유지하며, Cloudflare 저장소에 있던 화면 설정은 새 노션 설정 페이지에서 다시 선택합니다. 이전 Durable Object를 실제로 배포했던 Worker는 보존하고 새 Worker에 설치합니다. Bindings가 비어 있었던 테스트 Worker는 그대로 업데이트할 수 있습니다.

제작자는 `npm run build`로 두 배포 ZIP을 갱신합니다. 공용 Pages와 개인 Worker 모두 새 파일로 재배포해야 합니다. 실제 배포 및 사용자 노션 연결은 별도 검증해야 합니다.

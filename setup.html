HELP · 연결과 저장

연결이 잘 안 되나요?

“수집 기록을 확인하지 못했어요.”, “기록을 불러오지 못했어요. 설정을 닫고 다시 열어주세요.”는 여러 원인에 공통으로 표시되는 안내예요. 먼저 설정 창 상단의 상세 오류를 확인해주세요.

상세 오류는 여기에서 확인해요

  1. 위젯 오른쪽 위의 톱니바퀴 설정 버튼을 눌러주세요.
  2. 설정 창을 맨 위까지 스크롤해주세요.
  3. ‘메인화면 설정’ 제목 바로 아래의 회색 안내 상자를 확인해주세요. “함께할 포켓몬과 배경을 골라주세요.”보다 위쪽이에요.
  4. 상자에 표시된 문구와 같은 항목을 아래에서 펼쳐 확인해주세요. 연결 페이지에서 오류가 났다면 버튼 아래의 문구를 확인하면 돼요.

표시된 오류에 따라 확인해주세요

복제한 원본 DB 주소와 노션의 연결 추가 권한을 확인해주세요.
  1. 본인이 복제한 ‘포켓몬 수집 기록’ 원본 DB를 열어 링크를 다시 복사해주세요. 템플릿 배포 페이지·상위 일반 페이지·연결된 보기의 주소는 사용하지 않아요.
  2. 원본 DB 오른쪽 위의 ··· → 연결 → 연결 추가에서 본인이 만든 노션 연결을 추가해주세요.
  3. 연결이 검색되지 않으면 DB와 노션 연결이 같은 워크스페이스에 있는지 확인해주세요.
  4. 연결 설정에서 콘텐츠 읽기·삽입·업데이트를 허용해주세요. Worker의 NOTION_TOKEN도 이 DB에 추가한 연결의 토큰이어야 해요.
  5. 이 페이지에서 Worker 주소와 원본 DB 주소를 입력해 다시 연결해주세요.
개인 Worker에 연결하지 못했어요. / 허용되지 않은 위젯 주소입니다.

개인 Worker의 HTTPS 주소가 정확한지, 코드 교체 후 Deploy를 눌렀는지 확인해주세요.

이 사이트에서 사용하는 Worker의 일반 변수 WIDGET_ORIGIN은 https://pokemon.loraticon.com으로 설정해주세요. 경로·물음표·해시를 붙이지 않아요. “Worker의 WIDGET_ORIGIN 설정을 확인해주세요.”라는 문구도 같은 설정을 확인하면 돼요.

주소나 설정을 변경했다면 다시 배포하고, 이 페이지에서 새 위젯 링크를 만들어주세요.

노션 연결 토큰을 확인해주세요. / NOTION_TOKEN을 등록하고 배포해주세요.

Cloudflare Worker의 Settings → Variables and Secrets에서 종류 Secret, 이름 NOTION_TOKEN으로 노션 연결 토큰을 등록해주세요.

DB에 추가한 연결의 토큰인지 확인하고, 값을 변경했다면 다시 배포해주세요. 토큰은 이 사이트나 문의 메시지에 입력하지 않아요.

위젯 설정 페이지·설정 블록·설정 내용을 확인해주세요.

‘위젯 설정 페이지를 준비해주세요’라고 나오면 이 페이지에서 같은 Worker·DB 주소로 다시 연결해주세요. DB 안에 ‘위젯 설정’ 페이지가 자동으로 준비돼요.

‘설정 블록을 찾지 못했어요’ 또는 ‘설정 내용·형식을 확인해주세요’라고 나오면 ‘위젯 설정’ 페이지 안의 코드 블록을 변경하거나 삭제했는지 확인해주세요. 변경 전 내용을 복원하고 다시 시도해주세요. 복원이 어렵다면 상세 오류 문구와 설정 창 상단 화면을 알려주세요.

노션의 폼 식별자 '…'를 확인해주세요.

수집 DB에 수동으로 만든 빈 행·예시 행이나, 폼 식별자를 직접 변경한 기록이 있는지 확인해주세요.

폼 식별자 ''처럼 따옴표 안이 비어 있다면 식별자가 없는 행이 있어요. 실제 포켓몬 수집 기록이 아닌 빈 행·예시 행만 제거하고 다시 시도해주세요. 이미 수집한 기록의 식별자를 바꿨다면 원래 값으로 복원해주세요.

연결 페이지에서 링크가 만들어졌더라도, 기록을 읽는 단계에서 이런 오류가 발생할 수 있어요.

노션의 배경 식별자 '…'를 확인해주세요.

수집 기록의 ‘배경 식별자’를 직접 변경했는지 확인해주세요. 배경 이름이나 이미지 주소를 입력하는 칸이 아니에요. 위젯이 자동으로 저장했던 원래 식별자로 복원해주세요.

노션의 '…' 속성 유형을 확인해주세요. / DB 속성과 연결 설정을 확인해주세요.

노션 연결의 콘텐츠 읽기·삽입·업데이트 권한도 확인해주세요. 오류가 계속되면 최신 Worker 코드로 전체 교체하고 다시 배포해주세요.

노션 응답이 지연되고 있어요. / 노션 요청이 잠시 많아졌어요.

네트워크나 노션 응답이 늦어진 상태일 수 있어요. 잠시 기다린 뒤 위젯을 새로고침하고 다시 확인해주세요.

저장 중 오류가 났다면 노션 DB에 해당 포켓몬이 이미 추가됐는지 먼저 확인해주세요. 위젯에 ‘저장 상태 확인’ 버튼이 보이면 그 버튼을 눌러 확인해주세요.

Worker 코드를 복사하는 과정에서 한글이 깨졌을 가능성이 있어요. 최신 worker.js 받기 ↗로 파일을 다시 받아주세요.

Cloudflare의 Edit code에서 코드를 전체 교체하고 Deploy한 뒤 다시 연결해주세요. 기존 NOTION_TOKEN은 유지해요. 새 코드에 한글 대신 \uXXXX가 보이는 것은 정상이에요.

상세 오류 문구가 보이지 않나요?

  1. 노션에 임베드한 동일한 위젯 주소를 개인 기기의 브라우저에서 직접 열어주세요.
  2. 새로고침한 뒤 톱니바퀴 설정 버튼을 누르고, 설정 창 맨 위의 안내 상자를 확인해주세요.
  3. 브라우저에서는 정상인데 노션에서만 오류가 나면, 새로 만든 위젯 링크로 노션 임베드를 다시 넣어 확인해주세요.
  4. 브라우저에서도 문구가 보이지 않거나 오류가 계속되면, 설정 창 상단이 보이도록 화면을 캡처해주세요.

문의할 때는 상세 오류 문구와 설정 창 상단 화면을 함께 알려주세요. 캡처에 노션 API 토큰이나 개인 Worker·위젯 주소가 보이면 가려주세요.

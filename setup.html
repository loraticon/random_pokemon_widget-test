나의 노션에,
작은 포켓몬 도감.

하루의 작은 즐거움을 모아보세요.
잡은 포켓몬은 나만의 노션 도감에 차곡차곡 쌓여요.

01 노션 도감 준비→02 개인 Worker 설치→03 연결 & 임베드

처음 한 번만 준비해주세요

각 항목을 눌러 설치 순서를 확인하세요.

01노션에 수집 공간 만들기
  1. 본인만 사용하는 포켓몬 전용 워크스페이스를 만들고, 제공받은 수집 도감 템플릿을 복제하세요.
  2. 같은 워크스페이스에 노션 내부 연결을 만들고 콘텐츠 읽기·삽입·업데이트를 허용하세요.
  3. 복제한 원본 DB에서 ··· → 연결 추가를 열어 방금 만든 연결을 추가하세요.

DB 속성은 이름 · 폼 식별자 · 배경 식별자 · 즐겨찾기, 네 가지예요. 기존 워크스페이스의 비공개 페이지도 사용할 수 있어요.

02나만의 Worker 연결하기
  1. Cloudflare에서 Workers & Pages → Create application → Create Worker로 Worker를 만드세요. 이름은 pokemon-collection-widget을 추천해요.
  2. 아래 worker.js를 텍스트 편집기로 열어 전체 복사한 뒤, Worker의 Edit code에 전체 붙여넣고 Deploy하세요.
  3. Settings → Variables and Secrets에 NOTION_TOKEN을 Secret으로 추가하세요. 값에 노션 내부 연결 토큰을 넣고 배포하세요.

03 · CONNECT

이제, 도감을 연결해볼까요?

준비한 두 주소를 입력하면 노션에 넣을 위젯 링크가 만들어져요.

배포한 개인 Worker의 HTTPS 주소를 붙여넣으세요.

복제한 원본 데이터베이스에서 ‘링크 복사’로 가져오세요.

노션 API 토큰은 개인 Worker에만 등록해요. 이 화면에는 주소만 입력해주세요.

나만의 도감이 준비됐어요

아래 주소를 노션 페이지에 붙여넣고 임베드를 선택하세요.
자동 복사가 되지 않았다면 복사 버튼을 눌러주세요.

위젯 열기 ↗노션 도감 열기 ↗

나만의 공간에서 안전하게 사용해주세요

별도의 위젯용·설정용 토큰이 없어, Worker 주소와 위젯 주소를 아는 사람은 도감을 조회하거나 변경할 수 있어요. 개인 기기와 비공개 노션 페이지에서만 사용하고, 주소를 커뮤니티·SNS·공개 문서에 공유하지 마세요. 전용 워크스페이스도 주소 접근을 차단해주지는 않아요.

연결 시 DB에 ‘위젯 설정’ 페이지가 자동으로 추가돼요. 포획 횟수에는 포함되지 않으며, 배경 즐겨찾기와 슬립 설정을 여러 기기에서 공유하는 데 사용해요.

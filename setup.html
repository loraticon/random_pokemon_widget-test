포켓몬 수집 위젯 연결

나만의 노션 수집 도감을 만들고, 하루 3마리씩 포켓몬을 잡아보세요.

1. 포켓몬 전용 노션 공간 준비

다른 기록과 분리할 수 있도록 본인만 사용하는 포켓몬 전용 워크스페이스를 권장합니다. 노션 왼쪽 위 워크스페이스 메뉴에서 새 워크스페이스를 만든 뒤, 제공받은 수집 도감 템플릿을 그곳에 복제하세요.

해당 워크스페이스에서 내부 연결을 생성하고 콘텐츠 읽기·삽입·업데이트를 허용하세요. 복제한 원본 DB의 ··· → 연결 추가에서 이 연결을 추가합니다.

DB에는 이름·폼 식별자·배경 식별자·즐겨찾기 네 속성을 사용합니다. 기존 워크스페이스의 비공개 페이지에서도 연결할 수 있습니다.

2. 개인 Worker 준비

Cloudflare에 가입하고 Workers & Pages → Create application → Create Worker에서 개인 Worker를 만드세요. 이름은 pokemon-collection-widget을 권장합니다.

worker.js 받기 → 텍스트 편집기로 열고 전체 복사 → Worker의 Edit code에 전체 붙여넣기 → Deploy 순서로 진행하세요.

Settings → Variables and Secrets에서 이름 NOTION_TOKEN, 종류 Secret, 값은 노션 내부 연결 토큰으로 등록하고 배포합니다.

Node.js 설치·GitHub 연결·Bindings 추가는 필요 없습니다. 설치 안내 · worker.js와 안내 ZIP 받기

3. 도감 연결하고 노션에 삽입

DB의 링크를 복사해서 입력하세요. 연결하면 DB 안에 ‘위젯 설정’ 페이지가 자동 추가됩니다. 이 페이지는 도감·포획 횟수에서 제외하며 배경 즐겨찾기와 슬립 설정을 여러 기기에서 공유합니다.

별도의 위젯용·설정용 토큰은 없습니다. 노션 API 토큰은 이 화면에 입력하지 않고 개인 Worker에만 등록합니다.

노션에 위젯 삽입

아래 주소를 복사해 노션 페이지에 붙여넣고 임베드를 선택하세요.

위젯 열기 · 노션 수집 도감 열기

Worker 주소와 위젯 주소를 아는 사람은 도감을 조회하거나 변경할 수 있습니다. 주소를 공유하거나 공개 페이지에 넣지 마세요.

개인 사용 안내
본인의 개인 기기와 비공개 노션 페이지에서만 사용하세요. 공용 PC·공유 기기에서는 사용하지 말고, Worker 주소·위젯 주소를 커뮤니티·SNS·공개 문서에 올리지 마세요. 전용 워크스페이스를 만들어도 주소 접근이 자동으로 차단되지는 않습니다.
